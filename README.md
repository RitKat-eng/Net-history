
# Nätet Historia – The History of the Internet

## Project Overview

Nätet Historia is an educational website that explores the history and development of the internet.

The project was created as part of my Web Development studies at TUC Yrkeshögskola. It combines UI design and front-end development to present historical information in a clear, engaging and accessible way.

## Design

The website was designed in Figma before being developed using HTML, CSS and JavaScript.

- [View Figma Design](https://www.figma.com/design/LXfiNTGB8mrsUpCcJjIi4s/N%C3%A4tet-Historia?node-id=0-1)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Figma
- Git and GitHub

## Key Sections

- **Introduction:** An overview of the history of the internet.
- **Historical Timeline:** Important milestones in the development of the internet, from ARPANET to today.
- **Educational Resources:** Three learning sections providing additional information.
- **Explanatory Video:** A video section with supporting educational content.
- **Feedback Form:** A form designed to collect user feedback.
- **Responsive Design:** Desktop and mobile design layouts.

## Design Process

1. Planned the website structure and content.
2. Created the UI design and layout in Figma.
3. Developed the website using HTML, CSS and JavaScript.
4. Organized project files and assets.
5. Worked on adapting the layout for different screen sizes.
